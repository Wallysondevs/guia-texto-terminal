Vários comandos e scripts (-e, { }, -f)

Um script do sed pode ter vários comandos, agrupados por endereço e guardados num arquivo. Esta aula mostra como montar essas receitas.

Você vai aprender
  • Juntar comandos com -e e ;.
  • Agrupar comandos sob um endereço com { }.
  • Rodar um arquivo de script com -f e parar com q.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: uma receita com vários passos

Um script do sed pode ter vários comandos. Eles rodam em ordem, na mesma linha, antes de ela ser impressa. Há três jeitos de juntar: várias opções -e, o ponto e vírgula ; e as chaves { } para agrupar comandos sob um endereço. Quando a receita cresce, ela vai para um arquivo e roda com -f.

1. -e e ;

$ sed -e 's/rato/gato/g' -e 's/Rato/Gato/' texto.txt
O gato roeu a roupa do rei de Roma.
A rainha, com raiva, rasgou o resto.
O gato fugiu para o mato.
Gato que é gato não volta.
$ sed 's/rato/gato/g; s/Rato/Gato/' texto.txt
O gato roeu a roupa do rei de Roma.
A rainha, com raiva, rasgou o resto.
O gato fugiu para o mato.
Gato que é gato não volta.
$

As duas formas deram o mesmo resultado. A ordem importa: cada comando trabalha no resultado do anterior.

2. Chaves: vários comandos num endereço

Só nas linhas de ERRO: trocar ERRO por FALHA e espremer os dois espaços num só:

$ sed '/ERRO/{s/ERRO/FALHA/; s/  / /}' log.txt | head -3
2026-03-02 08:15:02 INFO  login usuario=ana
2026-03-02 08:17:45 FALHA falha no pagamento pedido=1042
2026-03-02 08:20:11 INFO  pedido criado pedido=1043
$
/ERRO/
endereço: as linhas com ERRO.
{
começa o grupo.
s/ERRO/FALHA/
1º comando do grupo.
; s/ / /
2º comando: dois espaços viram um.
}
fecha o grupo.

3. Um script em arquivo: -f

O arquivo limpa.sed dos exemplos tem três comandos, um por linha, e comentários com #. O -f (file) lê o script do arquivo:

$ cat limpa.sed
# limpa.sed: tira comentários e linhas vazias do config.txt
/^#/d
/^$/d
s/=/ = /
$ sed -f limpa.sed config.txt
nome = Loja da Ana
porta = 8080
debug = sim
email = contato@lojadaana.example
tema = claro
idioma = pt-BR
$
Script executável

Se a primeira linha do arquivo for #!/usr/bin/sed -f e ele tiver permissão de execução (chmod +x), dá para rodar como ./limpa.sed config.txt.

4. Comandos que param: q

O q (quit) imprime a linha atual e encerra o sed. 3q é um head -3; com um endereço de regex, para no primeiro achado:

$ sed '3q' log.txt
2026-03-02 08:15:02 INFO  login usuario=ana
2026-03-02 08:17:45 ERRO  falha no pagamento pedido=1042
2026-03-02 08:20:11 INFO  pedido criado pedido=1043
$ sed -n '/ERRO/{p;q}' log.txt
2026-03-02 08:17:45 ERRO  falha no pagamento pedido=1042
$

Quando dá errado

Chave sem fechar

Abriu {, tem de fechar com }:

$ sed '/ERRO/{s/ERRO/FALHA/' log.txt
sed: -e expressão #1, caractere 0: `{' sem correspondente
$
Script que não existe

O -f precisa de um arquivo de script que exista:

$ sed -f nada.sed config.txt
sed: não foi possível abrir o arquivo nada.sed: Arquivo ou diretório inexistente
$

Referência rápida

Você digitaO que faz
sed -e 'cmd1' -e 'cmd2'dois comandos.
sed 'cmd1; cmd2'o mesmo, com ;.
sed '/x/{cmd1; cmd2}'dois comandos só nas linhas com x.
sed -f script.sed arqlê o script de um arquivo.
sed '3q'para depois da linha 3.

Resumo

  • Os comandos rodam em ordem, na mesma linha.
  • { } agrupa comandos sob um endereço.
  • Receitas grandes vão para um arquivo .sed e rodam com -f.
