if, for e while

Dentro das chaves, o awk é uma linguagem completa. Esta aula mostra decisões e repetições, com exemplos de notas e logs.

Você vai aprender
  • if/else e o ternário.
  • for pelos campos e while.
  • next e exit.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: decisões e repetições

Dentro das chaves, o awk é uma linguagem de programação completa, com sintaxe parecida com a do C e do JavaScript: if/else para decidir, for e while para repetir, next para pular para a próxima linha e exit para parar.

1. if e else

A condição vai entre parênteses. Aprovado com média 7 ou mais:

$ awk '{m = ($2 + $3 + $4) / 3; if (m >= 7) print $1, "aprovado"; else print $1, "reprovado"}' notas.txt
Ana aprovado
Bruno reprovado
Carla aprovado
Diego reprovado
Eduarda aprovado
$

Com mais de um comando por ramo, use chaves. E há o operador ternário, condição ? a : b, para escolher um valor:

$ awk '{m = ($2 + $3 + $4) / 3; printf "%-8s %4.1f %s\n", $1, m, (m >= 7 ? "ok" : "recuperação")}' notas.txt
Ana       8.3 ok
Bruno     6.2 recuperação
Carla     9.5 ok
Diego     5.2 recuperação
Eduarda   7.8 ok
$

2. for: percorrer os campos

O for (i = 2; i <= NF; i++) passa por cada campo a partir do 2º. Aqui, a maior nota de cada aluno:

$ awk '{max = $2; for (i = 3; i <= NF; i++) if ($i > max) max = $i; print $1, max}' notas.txt
Ana 9.0
Bruno 7.0
Carla 10.0
Diego 6.5
Eduarda 8.5
$
max = $2
começa com a primeira nota.
for (i = 3; i <= NF; i++)
i vai de 3 até o último campo.
if ($i > max) max = $i
$i é o campo de número i.
print $1, max
nome e maior nota.

3. while

$ awk 'BEGIN {i = 1; while (i <= 5) {printf "%d ", i * i; i++}; print ""}'
1 4 9 16 25 
$

4. next e exit

next abandona a linha atual e vai para a próxima (aqui, pula comentários e linhas vazias). exit encerra o programa (indo para o END, se houver):

$ awk '/^#/ || /^$/ {next} {print "config:", $0}' config.txt
config: nome=Loja da Ana
config: porta=8080
config: debug=sim
config: email=contato@lojadaana.example
config: tema=claro
config: idioma=pt-BR
$ awk '$3 == "ERRO" {print "primeiro erro na linha", NR; exit}' log.txt
primeiro erro na linha 2
$

Quando dá errado

if sem parênteses

A condição do if precisa de parênteses:

$ awk '{if $2 > 7 print $1}' notas.txt
awk: lin. de com.:1: {if $2 > 7 print $1}
awk: lin. de com.:1:     ^ syntax error
$
