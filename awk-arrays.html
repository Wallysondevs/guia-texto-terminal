Arrays associativos

Um array associativo tem uma gaveta para cada etiqueta. É assim que o awk faz soma por vendedor e contagem por IP, a tabela dinâmica do terminal.

Você vai aprender
  • Contar e somar por chave.
  • Percorrer com for (k in a) e ordenar.
  • in, delete e o truque !visto[$0]++.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: uma gaveta para cada nome

Um array associativo é um conjunto de gavetas com etiqueta. Em vez de total, você usa total["Ana"], total["Bruno"]… e a etiqueta pode vir de um campo: total[$2] += $4. É o jeito do awk de fazer “soma por vendedor”, “conta por IP”, a tabela dinâmica da planilha.

1. Contar por chave

n[$3]++ soma 1 na gaveta do nível de cada linha. No END, o for (k in n) passa por todas as gavetas:

$ awk '{n[$3]++} END {for (k in n) print k, n[k]}' log.txt
ERRO 3
INFO 5
AVISO 2
$
n[$3]++
soma 1 na gaveta com o nome do campo 3.
for (k in n)
passa por cada etiqueta do array.
print k, n[k]
a etiqueta e o valor da gaveta.
A ordem do for in não é garantida

O awk não promete ordem nenhuma ao percorrer o array. Para ordenar, mande para o sort, como abaixo, ou use o recurso do gawk da seção 4.

2. Somar por chave

Faturamento por vendedor, ordenado do maior para o menor com o sort:

$ awk -F, 'NR > 1 {fat[$2] += $4 * $5} END {for (v in fat) printf "%s %.2f\n", v, fat[v]}' vendas.csv | sort -k2 -rn
Ana 277.30
Carla 209.90
Bruno 169.90
Diego 65.00
$

3. Contar IPs no log do servidor

$ awk '{n[$1]++} END {for (ip in n) print n[ip], ip}' acesso.log | sort -rn
4 192.168.0.12
3 192.168.0.20
3 192.168.0.15
2 192.168.0.33
$

4. Ordem no próprio gawk: PROCINFO["sorted_in"]

Só no gawk: definir PROCINFO["sorted_in"] escolhe a ordem do for in. "@ind_str_asc" é etiqueta em ordem alfabética; "@val_num_desc", valor numérico do maior para o menor:

$ awk '{n[$3]++} END {PROCINFO["sorted_in"] = "@ind_str_asc"; for (k in n) print k, n[k]}' log.txt
AVISO 2
ERRO 3
INFO 5
$ awk -F, 'NR > 1 {q[$3] += $4} END {PROCINFO["sorted_in"] = "@val_num_desc"; for (p in q) print p, q[p]}' vendas.csv
caneta 35
caderno 15
estojo 7
mochila 4
$

5. in e delete

(chave in array) testa se a gaveta existe; delete array[chave] apaga. O clássico “mostrar cada linha só na primeira vez” (um uniq que não precisa de sort) usa !visto[$0]++:

$ awk '!visto[$0]++' frutas.txt
banana
maçã
laranja
uva
$ awk -F, 'NR > 1 {v[$2]} END {print ("Diego" in v), ("Zeca" in v)}' vendas.csv
1 0
$

Quando dá errado

Array usado como número

Um array não tem valor único; imprimir o array inteiro é erro fatal:

$ awk '{n[$3]++} END {print n}' log.txt
awk: lin. de com.:1: (FILENAME=log.txt FNR=10) fatal: tentativa de usar vetor "n" em um contexto escalar
$

Exercícios

1. Contar

Complete para contar por vendedor:

awk -F, 'NR > 1 {n[]++} END {for (v in n) print v, n[v]}' vendas.csv

2. Percorrer

Complete o laço que passa pelas etiquetas:

END {for (k n) print k}

3. O for (k in n) devolve as chaves em que ordem?

4. O que awk '!visto[$0]++' frutas.txt faz?

Resumo

  • a[chave] cria a gaveta na hora.
  • O for in não tem ordem: use sort ou PROCINFO.
  • !visto[$0]++ tira repetidos sem ordenar.
