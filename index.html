Tutorial Texto no Terminal

Aprenda a editar, filtrar, somar e transformar texto direto no terminal do Linux, do zero, como numa escola: sed, awk e jq, um assunto por aula, com a saída de verdade de cada comando. Este guia complementa o Guia Bash: lá você aprende a usar o terminal; aqui, a fazer o trabalho pesado com texto.

Comece aqui ❯

A primeira aula é O que são sed, awk e jq. Depois vêm a pasta de teste com os arquivos de exemplo e, uma a uma, as aulas de cada comando.

Uma provinha

Três ferramentas encadeadas com o |: o grep acha as linhas de erro do log, o sed espreme os espaços duplos e o awk mostra só a hora e o último campo. Depois, o jq tira de um JSON só os nomes dos usuários ativos. Tudo isso foi rodado de verdade, na pasta de teste do guia:

$ grep ERRO log.txt | sed 's/  / /' | awk '{print $2, $NF}'
08:17:45 pedido=1042   « grep achou, sed limpou, awk recortou
09:12:03 e-mail
10:45:20 pedido=1047
$ jq -r '.[] | select(.ativo) | .nome' usuarios.json
Ana Souza   « o jq filtrou só os usuários ativos
Carla Dias
Diego Rocha
$

Parece grego? No fim do guia, você vai ler e escrever linhas assim sem esforço.

O que é este guia

Logs, planilhas em CSV, arquivos de configuração e respostas de APIs em JSON: quase tudo que passa por um computador é texto. O guia ensina as três ferramentas clássicas do Linux para trabalhar com ele:

  • sed, o editor de fluxo: troca palavras, apaga e insere linhas, edita arquivos sem abrir editor;
  • awk, a planilha de linha de comando: colunas, somas, médias, contagens e relatórios;
  • jq, o canivete do JSON: filtra, reorganiza e converte JSON em CSV.

São 42 aulas em cinco níveis, do básico (pipes, grep e regex) aos projetos completos (analisar um log, relatório de vendas, JSON para CSV). Cada aula ensina um assunto só. Os exemplos usam a usuária fictícia ana, no computador notebook, na pasta ~/guia-texto-teste, com arquivos inventados: os nomes, as vendas e os pedidos não são de ninguém.

O texto está em português do Brasil. As mensagens de erro não são traduzidas por nós: aparecem exatamente como os programas mostraram num Linux em português. O sed, o awk e o Bash já falam português; o jq só fala inglês, e a aula explica cada mensagem dele.

Como estudar

  1. Prepare a pasta de teste. A aula A pasta de teste e os arquivos de exemplo cria tudo com um script, sem internet.
  2. Leia com calma. A ideia, a anatomia do comando e a saída. Não pule a parte “Quando dá errado”.
  3. Rode no seu terminal. Este guia não simula o terminal: copie o comando, rode no seu Linux (ou no WSL do Windows, ou no macOS com as ferramentas GNU) e compare com a saída da aula.
  4. Faça as missões e os exercícios. Nas caixas Missão, cole o que o terminal respondeu e clique em Conferir.
A regra de ouro

Ler não basta: digite cada comando. As aspas simples, as barras e as chaves do sed, do awk e do jq só ficam naturais com prática. Comece aqui.

Versões de referência

Todas as saídas foram colhidas num Debian 13 em pt_BR.UTF-8, com GNU Bash 5.2, GNU sed 4.9, GNU awk (gawk) 5.2 e jq 1.7. O Ubuntu 24.04 traz as mesmas versões. No Ubuntu, instale o gawk e o jq com sudo apt install gawk jq; o awk que vem de fábrica é o mawk, e as aulas avisam quando algo é só do gawk.
