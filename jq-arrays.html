Listas (.[0], .[])

Muito JSON é uma lista de coisas parecidas. Esta aula mostra como pegar um item, uma fatia ou cada item da lista.

Você vai aprender
  • .[0], .[-1] e fatias.
  • .[]: um resultado por item.
  • Listas dentro de listas.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: listas e o “para cada”

Muito JSON é uma lista de coisas parecidas: usuários, pedidos, produtos. Com [n] você pega um item pela posição (começando em 0). Com [], sem número, o jq abre a lista e devolve cada item separado, e o que vier depois vale para cada um.

1. Posição: .[0], .[-1]

O usuarios.json é uma lista. .[0] é o primeiro; .[-1], o último:

$ jq '.[0]' usuarios.json
{
  "id": 1,
  "nome": "Ana Souza",
  "email": "ana@exemplo.com",
  "idade": 28,
  "cidade": "São Paulo",
  "ativo": true,
  "tags": [
    "admin",
    "vendas"
  ]
}
$ jq '.[-1].nome' usuarios.json
"Diego Rocha"
$

2. Fatias: .[1:3]

Do item 1 até antes do 3 (ou seja, o 2º e o 3º), devolvidos como lista:

$ jq -c '.[1:3]' produto.json
jq: error (at produto.json:1): Cannot index object with object
$ jq -c '.cores[1:]' produto.json
["verde","preto"]
$ jq -c '.cores[:2]' produto.json
["azul","verde"]
$

O primeiro comando deu erro: o produto.json é um objeto, não uma lista, e objeto não tem fatia. Nos dois seguintes, aplicada a .cores, que é lista, funciona: [1:] é “do 1 até o fim” e [:2], “do começo até antes do 2”.

3. .[]: cada item

O .[] devolve cada item da lista, um por resultado. Emendando .nome, sai o nome de cada um:

$ jq '.cores[]' produto.json
"azul"
"verde"
"preto"
$ jq '.[].nome' usuarios.json
"Ana Souza"
"Bruno Lima"
"Carla Dias"
"Diego Rocha"
$ jq '.pedidos[].cliente' pedidos.json
"Bruno"
"Carla"
"Diego"
"Ana"
$
.pedidos
a lista de pedidos.
[]
abre a lista: um resultado por pedido.
.cliente
de cada pedido, o cliente.

4. Listas dentro de listas

Cada pedido tem uma lista de itens. Dois [] abrem as duas camadas e dão todos os produtos de todos os pedidos:

$ jq '.pedidos[].itens[].produto' pedidos.json
"caderno"
"caneta"
"mochila"
"estojo"
"caneta"
"caderno"
$

5. .[] num objeto

Num objeto, .[] devolve os valores (sem as chaves):

$ jq '.estoque[]' produto.json
40
120
$

Quando dá errado

Número num objeto

[0] só funciona em listas. Num objeto, é erro (“Cannot index object with number”: não dá para indexar um objeto com número):

$ jq '.[0]' produto.json
jq: error (at produto.json:1): Cannot index object with number
$
Abrir um texto

[] abre listas e objetos, não textos (“Cannot iterate over string”: não dá para percorrer um texto):

$ jq '.nome[]' produto.json
jq: error (at produto.json:1): Cannot iterate over string ("caderno")
$
