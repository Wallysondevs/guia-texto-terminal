O que são sed, awk e jq

Três ferramentas pequenas, presentes em quase todo Linux, fazem o trabalho pesado com texto: editar, somar colunas e entender JSON. Esta aula apresenta as três, com uma provinha real de cada uma.

Você vai aprender
  • Para que serve cada ferramenta: sed, awk e jq.
  • Como ver as versões instaladas.
  • Por que o guia usa o gawk e o que muda no mawk.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: três ferramentas para mexer em texto

Quase tudo no Linux é texto: arquivos de configuração, logs, planilhas exportadas em CSV, respostas de APIs em JSON. Abrir cada arquivo num editor e mudar à mão funciona uma vez. Na décima vez, cansa. Este guia ensina três ferramentas que fazem esse trabalho sozinhas, direto no terminal:

  • sed (de stream editor, “editor de fluxo”): lê o texto linha a linha e edita: troca palavras, apaga linhas, insere texto.
  • awk (das iniciais dos criadores, Aho, Weinberger e Kernighan): enxerga cada linha como uma tabela de colunas e faz contas, filtros e relatórios.
  • jq (“JSON query”): entende JSON, o formato das APIs, e tira dele só o que você quer.

Uma provinha de cada uma, com os arquivos de exemplo do guia. O sed trocou “rato” por “gato”, o awk mostrou só a primeira coluna e o jq pegou o nome do primeiro usuário:

$ sed 's/rato/gato/' texto.txt
O gato roeu a roupa do rei de Roma.   « o sed trocou “rato” por “gato”
A rainha, com raiva, rasgou o resto.
O gato fugiu para o mato.
Rato que é gato não volta.
$ awk '{print $1}' notas.txt
Ana   « o awk mostrou a coluna 1
Bruno
Carla
Diego
Eduarda
$ jq '.[0].nome' usuarios.json
"Ana Souza"   « o jq tirou um campo do JSON
$

Repare na última linha do sed: “Rato que é gato não volta.” O “Rato” com R maiúsculo continuou igual, e o “rato” minúsculo virou “gato”, porque o s diferencia maiúsculas e troca só a primeira ocorrência de cada linha. Detalhes assim são o assunto do Nível 2.

gawk ou mawk?

Existem vários programas chamados awk. O guia usa o GNU awk (gawk). No Ubuntu e no Debian, o awk que vem instalado costuma ser o mawk, mais simples. Quase tudo do guia funciona nos dois; quando algo é só do gawk, a aula avisa. Para ter o mesmo resultado do guia, instale o gawk com sudo apt install gawk: depois disso, o comando awk passa a chamar o gawk.

Se o seu awk ainda for o mawk, ele nem entende --version. Na máquina da coleta o mawk também estava instalado, e foi assim que ele respondeu (a versão dele se pede com -W version):

Antes delas, o Nível 1 revisa o terreno em volta: pastas de teste, pipes e redirecionamento, e as ferramentas pequenas (cat, head, tail, wc, cut, sort, uniq, tr e grep). Se você nunca abriu um terminal, comece pelo Guia Bash, que este guia complementa.

Quando dá errado

Programa não instalado

Se uma ferramenta não estiver instalada, o Bash avisa com esta frase. Na coleta, pedimos de propósito um programa que não existe:

$ jqq --version
bash: linha 1: jqq: comando não encontrado
$

A solução é corrigir o nome ou instalar o programa: sudo apt install jq, por exemplo.
