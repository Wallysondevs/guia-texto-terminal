JSON para CSV (@csv e @tsv)

Transformar JSON em planilha é uma das tarefas mais pedidas. Os formatadores @csv e @tsv fazem isso.

Você vai aprender
  • @csv e @tsv com -r.
  • Cabeçalho e uma linha por item.
  • Variáveis com as $p para listas dentro de listas.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: do JSON para a planilha

Os formatadores @csv e @tsv transformam uma lista em uma linha de CSV (separada por vírgula, com textos entre aspas) ou TSV (separada por tabulação). Com -r, a linha sai pronta para gravar num arquivo e abrir na planilha.

1. @csv

Para cada usuário, monte uma lista com os campos na ordem das colunas e passe por @csv:

$ jq -r '.[] | [.id, .nome, .cidade, .idade] | @csv' usuarios.json
1,"Ana Souza","São Paulo",28
2,"Bruno Lima","Rio de Janeiro",35
3,"Carla Dias","Belo Horizonte",22
4,"Diego Rocha","São Paulo",41
$
.[]
cada usuário.
[.id, .nome, .cidade, .idade]
uma lista: as colunas, na ordem.
@csv
vira uma linha de CSV.
-r
sem as aspas externas do JSON.

2. Com cabeçalho

A vírgula do jq produz primeiro a lista do cabeçalho, depois as linhas:

$ jq -r '["id", "nome", "email"], (.[] | [.id, .nome, .email]) | @csv' usuarios.json
"id","nome","email"
1,"Ana Souza","ana@exemplo.com"
2,"Bruno Lima","bruno@exemplo.com"
3,"Carla Dias",
4,"Diego Rocha","diego@exemplo.com"
$

Repare: o email nulo da Carla virou um campo vazio.

3. @tsv

TSV usa tabulação e não põe aspas: ótimo para o awk e para o column:

$ jq -r '.pedidos[] | [.id, .cliente, .status] | @tsv' pedidos.json
1042	Bruno	pago
1043	Carla	pendente
1044	Diego	pago
1045	Ana	cancelado
$ jq -r '.pedidos[] | [.id, .cliente, .status] | @tsv' pedidos.json | awk -F'\t' '$3 == "pago" {print $2}'
Bruno
Diego
$

4. Uma linha por item de pedido

Para listas dentro de listas, guarde o pai numa variável com as $p e abra os filhos:

$ jq -r '.pedidos[] as $p | $p.itens[] | [$p.id, $p.cliente, .produto, .qtd, .preco] | @csv' pedidos.json
1042,"Bruno","caderno",2,12.5
1042,"Bruno","caneta",5,2.0
1043,"Carla","mochila",1,89.9
1044,"Diego","estojo",1,15.0
1044,"Diego","caneta",3,2.0
1045,"Ana","caderno",4,12.5
$

5. Gravar e conferir

$ jq -r '.[] | [.id, .nome, .cidade] | @csv' usuarios.json > usuarios.csv
$ wc -l usuarios.csv
4 usuarios.csv
$ awk -F, '{print $2}' usuarios.csv
"Ana Souza"
"Bruno Lima"
"Carla Dias"
"Diego Rocha"
$

Quando dá errado

@csv num objeto

O @csv só aceita listas (“cannot be csv-formatted, only array”: não pode virar CSV, só lista):

$ jq -r '.[0] | @csv' usuarios.json
jq: error (at usuarios.json:6): object ({"id":1,"no...) cannot be csv-formatted, only array
$
Lista dentro da linha

Cada coluna tem de ser um valor simples. A lista de tags não cabe numa célula (“is not valid in a csv row”: não vale numa linha de CSV):

$ jq -r '.[0] | [.nome, .tags] | @csv' usuarios.json
jq: error (at usuarios.json:6): array (["admin","v...) is not valid in a csv row
$

Junte antes: (.tags | join(";")).

Referência rápida

[.a, .b] | @tsvlinha TSV.
