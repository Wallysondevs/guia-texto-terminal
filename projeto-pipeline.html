Projeto final: tudo junto

O projeto final cruza os três tipos de arquivo da loja: log de texto, CSV e JSON. Cada ferramenta faz a parte em que é melhor.

Você vai aprender
  • Levar dados do texto para o jq com um for.
  • Escrever JSON com awk e agrupar com jq -s.
  • Escolher a ferramenta certa para cada tarefa.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

O problema

O log do sistema (log.txt) diz que dois pagamentos falharam. Quem eram esses clientes? A resposta está no pedidos.json. E, de quebra, o chefe quer o total por vendedor em JSON, para mandar a outro sistema. É hora de juntar grep, sed, awk e jq.

1. Tirar os números dos pedidos do log

grep acha as linhas; sed apaga tudo até pedido=, sobrando só o número:

$ grep 'falha no pagamento' log.txt | sed -E 's/.*pedido=//'
1042
1047
$

2. Procurar cada pedido no JSON

Um for passa por cada número e o jq procura o pedido com --argjson (o id é número). Com -e, o jq sai com erro quando não acha nada, e o || avisa:

$ for id in $(grep 'falha no pagamento' log.txt | sed -E 's/.*pedido=//'); do jq -e -r --argjson id "$id" '.pedidos[] | select(.id == $id) | "\(.id) \(.cliente) \(.status)"' pedidos.json || echo "$id não está no pedidos.json"; done
1042 Bruno pago
1047 não está no pedidos.json
$

O pedido 1047 está no log, mas não no pedidos.json: uma pista de que a exportação está desatualizada. Achar isso à mão, num log grande, levaria muito mais tempo.

3. De CSV para JSON

Agora o caminho contrário. O awk escreve um objeto JSON por linha (as aspas do JSON vão com \" dentro do printf):

$ awk -F, 'NR > 1 {printf "{\"vendedor\":\"%s\",\"valor\":%s}\n", $2, $4 * $5}' vendas.csv | head -3
{"vendedor":"Ana","valor":37.5}
{"vendedor":"Bruno","valor":20}
{"vendedor":"Carla","valor":89.9}
$

E o jq -s junta todos numa lista, agrupa por vendedor e soma:

$ awk -F, 'NR > 1 {printf "{\"vendedor\":\"%s\",\"valor\":%s}\n", $2, $4 * $5}' vendas.csv | jq -s -c 'group_by(.vendedor) | map({vendedor: .[0].vendedor, total: (map(.valor) | add)})'
[{"vendedor":"Ana","total":277.3},{"vendedor":"Bruno","total":169.9},{"vendedor":"Carla","total":209.9},{"vendedor":"Diego","total":65}]
$

4. O painel

O painel.sh é o projeto final: cada linha usa a ferramenta certa para o arquivo certo, e o resultado é um resumo da loja inteira:

$ cat painel.sh
#!/usr/bin/env bash
# painel.sh: resumo dos arquivos da loja (projeto final do Nível 5)
echo "== Painel da Papelaria =="
echo "Erros no log do sistema: $(grep -c ERRO log.txt)"
echo "Respostas 5xx no site:   $(awk '$9 >= 500' acesso.log | wc -l)"
total=$(awk -F, 'NR > 1 {t += $4 * $5} END {printf "%.2f", t}' vendas.csv | tr . ,)
echo "Vendas no CSV:           R\$ $total"
echo "Pedidos pagos no JSON:   $(jq '[.pedidos[] | select(.status == "pago")] | length' pedidos.json)"
echo "Pagamentos que falharam:"
grep 'falha no pagamento' log.txt | sed -E 's/^([0-9-]+) ([0-9:]+).*pedido=([0-9]+)$/  \1 \2  pedido \3/'
$ bash painel.sh

Vendas no CSV:           R$ 722,10
Pedidos pagos no JSON:   2

  2026-03-02 08:17:45  pedido 1042
  2026-03-02 10:45:20  pedido 1047

Qual ferramenta, quando?

TarefaFerramenta
achar linhasgrep
trocar ou recortar texto numa linhased
colunas, contas, contagens, relatóriosawk
qualquer coisa em JSONjq
ordenar e contar repetidossort e uniq -c

Quando dá errado

--arg em vez de --argjson

Com --arg, o id vira o texto "1042", que nunca é igual ao número 1042 do JSON. Não sai nada e nenhum erro aparece, só o “fim”:

$ for id in $(grep 'falha no pagamento' log.txt | sed -E 's/.*pedido=//'); do jq -r --arg id "$id" '.pedidos[] | select(.id == $id) | .cliente' pedidos.json; done; echo fim
fim
$
\d no sed

O sed não conhece \d (isso é do Perl e do Python). A regex não casa e a linha sai inteira, sem troca. Use [0-9]:

$ grep 'falha no pagamento' log.txt | sed -E 's/.*pedido=(\d+)$/\1/'
2026-03-02 08:17:45 ERRO  falha no pagamento pedido=1042
2026-03-02 10:45:20 ERRO  falha no pagamento pedido=1047
$

Resumo

  • Cada ferramenta tem seu forte: grep acha, sed troca, awk conta, jq entende JSON.
  • Número e texto são diferentes no jq: --argjson para números.
  • O sed usa [0-9], não \d.
