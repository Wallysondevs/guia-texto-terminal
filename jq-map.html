map, length, keys e add

Transformar cada item e continuar com uma lista, contar, somar, listar chaves: as funções que olham a lista inteira.

Você vai aprender
  • map.
  • length, keys e has.
  • add, min, max e a média.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: trabalhar com a lista inteira

O .[] desmonta a lista em itens soltos. Às vezes você quer continuar com uma lista: transformar cada item e receber a lista de volta. Para isso existe o map. E há funções que olham a lista toda: length (tamanho), keys (chaves), add (soma), min, max.

1. map

map(.nome) devolve uma lista só com os nomes. É o mesmo que [.[] | .nome], os colchetes juntando os resultados numa lista:

$ jq -c 'map(.nome)' usuarios.json
["Ana Souza","Bruno Lima","Carla Dias","Diego Rocha"]
$ jq -c '[.[] | .nome]' usuarios.json
["Ana Souza","Bruno Lima","Carla Dias","Diego Rocha"]
$ jq -c 'map(.idade + 1)' usuarios.json
[29,36,23,42]
$

2. length

Tamanho de uma lista, número de chaves de um objeto, letras de um texto:

$ jq 'length' usuarios.json
4
$ jq '.pedidos | length' pedidos.json
4
$ jq '.[] | .tags | length' usuarios.json
2
1
0
1
$ jq '.nome | length' produto.json
7
$

3. keys e has

keys lista as chaves de um objeto (em ordem alfabética); has("chave") diz se ela existe:

$ jq -c 'keys' produto.json
["cores","estoque","nome","preco"]
$ jq -c '.[0] | keys' usuarios.json
["ativo","cidade","email","id","idade","nome","tags"]
$ jq 'has("preco"), has("peso")' produto.json
true
false
$

4. add, min, max e a média

add soma os itens de uma lista. Com length, dá a média:

$ jq 'map(.idade) | add' usuarios.json
126
$ jq 'map(.idade) | add / length' usuarios.json
31.5
$ jq 'map(.idade) | min, max' usuarios.json
22
41
$
map(.idade)
lista com as idades: [28,35,22,41].
add
soma: 126.
/ length
divide pela quantidade: 4.

5. map com select

Dentro do map, o select filtra e a lista volta menor. Quantos usuários ativos?

$ jq 'map(select(.ativo)) | length' usuarios.json
3
$ jq -c '.pedidos | map(select(.status != "cancelado") | .id)' pedidos.json
[1042,1043,1044]
$

Quando dá errado

keys de um texto

Texto não tem chaves (“has no keys”):

$ jq '.nome | keys' produto.json
jq: error (at produto.json:1): string ("caderno") has no keys
$
map num objeto

No jq 1.7, map num objeto passa pelos valores; aqui, os valores 40 e 120 não têm o campo nome (“Cannot index number”):

$ jq 'map(.nome)' <<< '{"a": 40, "b": 120}'
jq: error (at <stdin>:1): Cannot index number with string "nome"
$

Resumo

  • map(f) = [.[] | f].
  • length mede listas, objetos e textos.
  • add / length é a média.
