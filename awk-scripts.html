Scripts awk (-f), -v e funções

Quando o programa cresce, ele vai para um arquivo .awk. Esta aula mostra como rodar, como tornar executável, como parametrizar e como criar funções.

Você vai aprender
  • Rodar um arquivo com -f.
  • Script executável com #!/usr/bin/awk -f.
  • Parâmetros com -v e funções com function.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: programas awk em arquivo

Quando o programa passa de uma linha, fica ruim de digitar entre aspas. Coloque-o num arquivo .awk e rode com -f. Dentro do arquivo não precisa de aspas simples, dá para quebrar linhas, indentar e comentar com #.

1. -f: rodar um arquivo

O relatorio.awk dos exemplos calcula o faturamento por vendedor:

$ cat relatorio.awk
# relatorio.awk: total vendido por vendedor (vendas.csv)
BEGIN { FS = "," }
NR > 1 { total[$2] += $4 * $5 }
END {
    for (v in total)
        printf "%-8s R$ %8.2f\n", v, total[v]
}
$ awk -f relatorio.awk vendas.csv | sort
Ana      R$   277.30
Bruno    R$   169.90
Carla    R$   209.90
Diego    R$    65.00
$

2. Script executável

Com a primeira linha #!/usr/bin/awk -f e permissão de execução, o arquivo vira um comando. Na coleta, o script foi criado com printf para caber numa linha:

$ printf '#!/usr/bin/awk -f\n{ print NR ": " $1 }\n' > numera.awk
$ chmod +x numera.awk
$ ./numera.awk notas.txt
1: Ana
2: Bruno
3: Carla
4: Diego
5: Eduarda
$

3. -v com -f

O -v passa valores para o script, que fica reaproveitável: o mesmo filtro para níveis diferentes:

$ printf '$3 == nivel { print $2, $4 }\n' > filtra.awk
$ awk -v nivel=ERRO -f filtra.awk log.txt
08:17:45 falha
09:12:03 tempo
10:45:20 falha
$ awk -v nivel=AVISO -f filtra.awk log.txt
09:01:37 estoque
11:02:15 disco
$

4. Funções

No awk você pode criar funções com function nome(parâmetros) { ... }. Aqui, uma que formata dinheiro:

$ awk -F, 'function reais(v) {return sprintf("R$ %.2f", v)} NR > 1 {print $3, reais($4 * $5)}' vendas.csv | head -3
caderno R$ 37.50
caneta R$ 20.00
mochila R$ 89.90
$

Quando dá errado

Script que não existe

O -f precisa de um arquivo que exista:

$ awk -f nada.awk notas.txt
awk: fatal: não foi possível abrir arquivo-fonte "nada.awk" para leitura: Arquivo ou diretório inexistente
$
