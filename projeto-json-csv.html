Projeto: de JSON para planilha

Dados de API chegam em JSON; o financeiro quer planilha. Este projeto faz a ponte com o jq e confere o resultado com awk.

Você vai aprender
  • Uma linha de CSV por item, com as $p.
  • Tratar null e listas na hora de exportar.
  • Somar o CSV gerado com awk, sem cair nas aspas.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

O problema

O sistema de pedidos exporta pedidos.json, mas o financeiro quer uma planilha: uma linha por item, com o pedido, o cliente, o status e o subtotal. Depois, ainda pedem o total só dos pedidos pagos.

1. Ver a forma do dado

$ jq -c '.pedidos[0]' pedidos.json
{"id":1042,"cliente":"Bruno","status":"pago","itens":[{"produto":"caderno","qtd":2,"preco":12.5},{"produto":"caneta","qtd":5,"preco":2.0}]}
$

Cada pedido tem uma lista itens. Como uma linha do CSV é um item, o pedido (pai) precisa ser guardado numa variável com as $p.

2. O conversor

O pedidos-para-csv.sh escreve o cabeçalho e, para cada item, uma lista com os dados do pedido e do item, terminando em @csv:

$ cat pedidos-para-csv.sh
#!/usr/bin/env bash
# pedidos-para-csv.sh: uma linha de CSV por item de pedido (projeto do Nível 5)
arq="${1:-pedidos.json}"
jq -r '
  ["pedido", "cliente", "status", "produto", "qtd", "preco", "subtotal"],
  (.pedidos[] as $p | $p.itens[] |
    [$p.id, $p.cliente, $p.status, .produto, .qtd, .preco, (.qtd * .preco)])
  | @csv' "$arq"
$ bash pedidos-para-csv.sh
"pedido","cliente","status","produto","qtd","preco","subtotal"
1042,"Bruno","pago","caderno",2,12.5,25
1042,"Bruno","pago","caneta",5,2.0,10
1043,"Carla","pendente","mochila",1,89.9,89.9
1044,"Diego","pago","estojo",1,15.0,15
1044,"Diego","pago","caneta",3,2.0,6
1045,"Ana","cancelado","caderno",4,12.5,50
$
.pedidos[] as $p
para cada pedido, guarda o pedido em $p.
$p.itens[]
e passa por cada item dele.
(.qtd * .preco)
o subtotal, calculado na hora.
@csv
vira uma linha de CSV, com aspas nos textos.

4. Somar os pagos com awk

O CSV do @csv tem aspas nos textos. Tire as aspas com tr -d '"' antes de comparar:

$ bash pedidos-para-csv.sh | tr -d '"' | awk -F, '$3 == "pago" {t += $7} END {print t + 0}'
56
$

Pedidos pagos: 1042 (25 + 10) e 1044 (15 + 6), total 56.

5. Campos nulos e listas

No usuarios.json, a Carla não tem e-mail e as tags são uma lista. O // troca o null por vazio e o join transforma a lista em texto:

$ jq -r '.[] | [.nome, .email // "", (.tags | join(";"))] | @csv' usuarios.json
"Ana Souza","ana@exemplo.com","admin;vendas"
"Bruno Lima","bruno@exemplo.com","vendas"
"Carla Dias","",""
"Diego Rocha","diego@exemplo.com","suporte"
$

Quando dá errado

Comparar com as aspas lá dentro

O campo do status é "pago", com aspas. Comparado com pago, nunca é igual, e o total dá 0:

$ bash pedidos-para-csv.sh | awk -F, '$3 == "pago" {t += $7} END {print t + 0}'
0
$
Arquivo com outra forma

O produto.json não tem .pedidos: o jq recebe null e não consegue passar por ele (“Cannot iterate over null”: não dá para percorrer null). O cabeçalho ainda saiu, porque vem antes dos pedidos; a mensagem de erro apareceu primeiro porque a saída de erro não espera na fila:

$ bash pedidos-para-csv.sh produto.json
jq: error (at produto.json:1): Cannot iterate over null (null)
"pedido","cliente","status","produto","qtd","preco","subtotal"
$
