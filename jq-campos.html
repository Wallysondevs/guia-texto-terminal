Campos (.campo, .a.b)

Num objeto JSON, .chave pega o valor. Esta aula mostra o caminho até qualquer dado, por mais fundo que esteja.

Você vai aprender
  • .campo e .a.b.c.
  • Vários campos com vírgula.
  • Chave inexistente (null) e chaves com caracteres especiais.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: um caminho até o dado

Num objeto JSON, cada valor tem uma chave. Em jq, .chave pega o valor dessa chave. Para descer em objetos dentro de objetos, emende: .estoque.loja. É como um endereço: rua, número, apartamento.

1. Um campo

$ jq '.nome' produto.json
"caderno"
$ jq '.preco' produto.json
12.5
$ jq '.cores' produto.json
[
  "azul",
  "verde",
  "preto"
]
$

Repare: o texto veio com aspas, porque o jq devolve JSON. A aula de -r mostra como tirar as aspas.

2. Campos aninhados

$ jq '.estoque' produto.json
{
  "loja": 40,
  "deposito": 120
}
$ jq '.estoque.deposito' produto.json
120
$ jq '.pedidos[0].itens[0].produto' pedidos.json
"caderno"
$
.pedidos
a lista de pedidos.
[0]
o primeiro pedido.
.itens[0]
o primeiro item dele.
.produto
o nome do produto.

3. Vários campos de uma vez

A vírgula produz vários resultados, um depois do outro:

$ jq '.nome, .preco, .estoque.loja' produto.json
"caderno"
12.5
40
$

4. Campo que não existe: null

Pedir uma chave que não existe não é erro: o jq devolve null (“nada”). A aula de null mostra como tratar isso.

$ jq '.peso' produto.json
null
$

5. Chaves com caracteres especiais

Se a chave tiver espaço, hífen ou acento, use aspas: ."nome da chave", ou a forma de colchetes .["nome da chave"]:

$ echo '{"data-de-entrega": "2026-03-10"}' | jq '."data-de-entrega"'
"2026-03-10"
$ echo '{"data-de-entrega": "2026-03-10"}' | jq '.["data-de-entrega"]'
"2026-03-10"
$

Quando dá errado

Entrar num número

.estoque.loja é o número 40. Pedir uma chave dentro de um número é erro (“Cannot index number with string "x"”: não dá para indexar um número com o texto “x”):

$ jq '.estoque.loja.x' produto.json
jq: error (at produto.json:1): Cannot index number with string "x"
$
Hífen sem aspas

Sem aspas, o jq lê .data-de-entrega como uma conta: .data menos de menos entrega, e de não é uma função conhecida:

$ echo '{"data-de-entrega": "x"}' | jq '.data-de-entrega'
jq: error: de/0 is not defined at <top-level>, line 1:
.data-de-entrega      
jq: error: entrega/0 is not defined at <top-level>, line 1:
.data-de-entrega         
jq: 2 compile errors
$
