Montando objetos e listas

O jq também constrói JSON: só os campos que interessam, com nomes novos e campos calculados.

Você vai aprender
  • {nome, cidade} e campos renomeados.
  • Listas com [ ] e chaves calculadas.
  • Mudar e apagar campos: =, +=, del.

Todas as saídas desta aula foram colhidas de verdade num Linux (Debian 13, com GNU Bash 5.2, GNU sed 4.9, GNU awk 5.2 e jq 1.7) em português (pt_BR.UTF-8), dentro da pasta de teste ~/guia-texto-teste com os arquivos de exemplo. Antes de cada caixa a pasta foi recriada do zero, então um comando que altera arquivo numa caixa não afeta a seguinte.

A ideia: montar o JSON que você quer

Além de extrair, o jq constrói: { } monta objetos e [ ] monta listas. É assim que se tira só o necessário de uma resposta grande de API, se renomeia campos e se calcula campos novos.

1. Objetos com campos escolhidos

{nome, cidade} é um atalho para {nome: .nome, cidade: .cidade}:

$ jq -c '.[] | {nome, cidade}' usuarios.json
{"nome":"Ana Souza","cidade":"São Paulo"}
{"nome":"Bruno Lima","cidade":"Rio de Janeiro"}
{"nome":"Carla Dias","cidade":"Belo Horizonte"}
{"nome":"Diego Rocha","cidade":"São Paulo"}
$

2. Renomear e calcular

Do lado esquerdo do :, o nome novo; do direito, qualquer filtro:

$ jq -c '.pedidos[] | {pedido: .id, cliente, itens: (.itens | length), total: (.itens | map(.qtd * .preco) | add)}' pedidos.json
{"pedido":1042,"cliente":"Bruno","itens":2,"total":35}
{"pedido":1043,"cliente":"Carla","itens":1,"total":89.9}
{"pedido":1044,"cliente":"Diego","itens":2,"total":21}
{"pedido":1045,"cliente":"Ana","itens":1,"total":50}
$
pedido: .id
renomeia id para pedido.
cliente
mantém o cliente.
itens: (.itens | length)
um campo calculado: quantos itens.
total: (... | add)
soma de qtd × preço.

3. Montar listas com [ ]

Colchetes em volta de um filtro juntam todos os resultados numa lista:

$ jq -c '[.[] | select(.ativo) | .id]' usuarios.json
[1,3,4]
$ jq -c '{loja, clientes: [.pedidos[].cliente]}' pedidos.json
{"loja":"Papelaria da Ana","clientes":["Bruno","Carla","Diego","Ana"]}
$

4. Chave calculada: (expr): valor

Com parênteses, a chave também vem de um filtro. Com add, os objetos pequenos viram um só, um “dicionário” de nome para idade:

$ jq -c '.[] | {(.nome): .idade}' usuarios.json
{"Ana Souza":28}
{"Bruno Lima":35}
{"Carla Dias":22}
{"Diego Rocha":41}
$ jq -c 'map({(.nome): .idade}) | add' usuarios.json
{"Ana Souza":28,"Bruno Lima":35,"Carla Dias":22,"Diego Rocha":41}
$

5. Mudar um campo e manter o resto

.campo = valor devolve o objeto inteiro com o campo trocado; += soma; del(.campo) remove:

$ jq -c '.preco = 13.9' produto.json
{"nome":"caderno","preco":13.9,"estoque":{"loja":40,"deposito":120},"cores":["azul","verde","preto"]}
$ jq -c '.estoque.loja += 10 | del(.cores)' produto.json
{"nome":"caderno","preco":12.5,"estoque":{"loja":50,"deposito":120}}
$

Quando dá errado

Faltou o dois-pontos

Dentro de {{ }}, cada campo é chave: valor ou só o nome do campo. Um filtro solto quebra a sintaxe:

$ jq '.[] | {nome .idade}' usuarios.json
jq: error: syntax error, unexpected FIELD, expecting '}' (Unix shell quoting issues?) at <top-level>, line 1:
.[] | {nome .idade}            
jq: 1 compile error
$

Resumo

  • { } monta objetos; [ ], listas.
  • Campos calculados vão entre parênteses.
  • = e del devolvem o objeto inteiro modificado.
